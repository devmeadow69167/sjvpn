## 直连机场意味着什么

直连是指用户设备直接连到境外落地服务器，中间没有国内中转或专线入口。它的成本结构决定了价格可以压得很低，也决定了晚高峰跨境链路拥塞时没有备用路径可切换。

判断一分机场是否适合自己，第一步不是看价格，而是接受“直连”这个前提：白天与非高峰时段可用性通常可以接受，晚高峰体验取决于本地运营商到落地服务器的国际出口状况，服务方无法控制。第三方页面对此的表述是“稳定性和解锁不用指望太多，一分钱一分货”。这句话是评价，不是测试数据，但它与直连类型的物理约束一致。

如果主要用途是晚间流媒体或对延迟敏感的实时应用，直连类型本身就是否决项，与这家品牌是否诚信无关。

## “专线”标注为什么不能当真

第三方记录里有一条值得单独拿出来的说明：节点命名中标注的专线，实际也是直连线路。这不是对一分机场的指控，而是对整个 x 元、x 分价位段的普遍提醒。IPLC 或 IEPL 专线的带宽成本远高于这类套餐的定价，价格与线路类型在物理上对不上。

可操作判断：看到节点名里的“专线”“IPLC”字样时，用一次晚高峰 traceroute 或延迟对比就能分辨。真专线的路径不会经过公网国际出口，抖动明显更小。做不到测试时，按直连处理，不按专线付费。

## 协议、客户端与订阅怎么核对

第三方记录的协议是 VLESS 与 Hysteria2。这两种协议对客户端有要求：需要基于 Xray 或 sing-box 内核、且支持 Hysteria2 的客户端，旧版 Clash 内核不支持。购买前先确认自己常用设备上的客户端版本，再决定是否付款。

服务方自述提供订阅链接与教程、软件下载入口。这些入口是否仍可访问、订阅格式是否与你的客户端兼容，需要在付款前用免费方式验证。该品牌注册无试用，因此验证只能靠最短周期付费完成，这一点在成本表里要算进去。

订阅导入后至少检查三项：节点列表是否与第三方记录的五个地区一致、更新订阅是否成功、切换节点后 IP 归属地是否与节点名称一致。

## 适合谁，不适合谁

适合：预算极低、白天或非高峰使用为主、能接受偶发不可用、愿意用月付做短周期验证的用户。

不适合：需要晚高峰稳定、需要专线级延迟、依赖固定解锁地区、多人共享账号、或者需要退款保障的用户。

这个判断基于类型特征与服务方标称的限制，不是对该品牌当前服务质量的评分。同一类型的直连机场之间仍可能差异很大，只有带日期的自测能给出结论。

## 一套可复查的核验流程

1. **确认官网入口**：在官方公告、订单页与付款页三处看到同一域名，才算闭环；记录核对日期。
2. **确认协议与客户端**：核对自己设备上的客户端是否支持 VLESS 与 Hysteria2；记录客户端名称与版本。
3. **读取限制条款**：抄录设备上限、每日用量限制、流量重置周期与退款条款原文；缺失的写“未找到”。
4. **计算一次实付**：写下最短周期的支付总额、有效期、流量、倍率，不用折扣率比较。
5. **用最短周期验证**：付款后连续三个工作日在 21:00 前后测试常用节点，记录成功次数、延迟与失败原因。
6. **形成有限结论**：只写明测试日期、入口、节点与时段覆盖范围，未覆盖的场景保持未知。
