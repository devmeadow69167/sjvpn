## 下单去向有哪些区别？

把不同入口组放在一起看，它们引导下单或注册的去向互不相同；其中 `.cyou` 与 `.cfd` 是已观察到的相同一组。不能把“去向有差别”理解成每个域名都各有一个独立去向，也不能据此断定运营关系。

这些入口的首页没有相互指向其他星辰域名。名称相近、页面用词相似，都不足以补上这种联系。对于读者来说，应把当前打开的地址与准备使用的账号对应起来，避免在几个同名入口反复注册。

## 登录前先核对什么？

查看地址栏中的完整域名，再读页面署名和身份说明。标题里的“官网”只是页面自称，不能单独作为登录或付款的依据。备案编号也应与自称身份分开理解，看到编号文字不等于已经核验。

这些页面没有给出能用于确认品牌归属的公司名称和具体联系方式。`.cyou` 与 `.cfd` 虽然存在相同的注册资料字段，但这些共同点仍不足以确认持有人身份。

## 常见问题

### 哪个入口能认作星辰vpn 官网？

现有页面信息不足以确认。部分入口在标题或页脚自称官网，但没有可用于确认品牌归属的公司资料和具体联系信息，不能据此指定其中一个。

### 下单去向不同，是否说明不是同一家？

不能这样判断。观察到的是不同入口组的去向有差别，其中还有两个域名使用相同去向；这些现象都不足以确定背后的运营关系。

### GitHub 上的说明文档能证明入口身份吗？

不能单凭文档认定。相关仓库由第三方整理，提供的是它自己的注册入口，也没有列出表中几个中文同名域名来建立联系，仍需单独核对身份依据。
